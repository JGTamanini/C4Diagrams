# 2.6 Fora do Escopo

Esta seção define explicitamente o que o sistema não irá contemplar em sua versão inicial, evitando expansão não planejada do escopo do projeto.

---

## 2.6.1 Interface e Plataforma

- O sistema **não** oferecerá suporte a dispositivos móveis ou tablets
- O sistema **não** contará com modo offline — é necessária conexão com a internet para utilização
- O sistema **não** será otimizado para responsividade — a resolução mínima suportada é 1280×720px, conforme definido no RNF11

## 2.6.2 Colaboração

- O sistema **não** oferecerá edição colaborativa em tempo real entre múltiplos usuários
- O sistema **não** contará com funcionalidades de comentários ou revisão de diagramas por terceiros

## 2.6.3 Integração e Importação

- O sistema **não** realizará importação automática de diagramas criados em outras ferramentas (Draw.io, Lucidchart, diagrams.net)
- O sistema **não** oferecerá integração com IDEs ou ferramentas de versionamento de código — a exportação em formato Docs-as-Code (RF21) gera um arquivo portável, mas não realiza commits ou push automáticos para repositórios
- O sistema **não** gerará diagramas automaticamente a partir de análise de código-fonte
- O sistema **não** oferecerá sincronização bidirecional entre canvas e texto — a entrada textual converte texto em elementos visuais (texto → canvas), mas alterações feitas no canvas não são refletidas em texto

## 2.6.4 Modelos de Diagramação

- O sistema **não** oferecerá suporte a outros modelos de diagramação além do C4, como UML, BPMN ou ArchiMate

## 2.6.5 Infraestrutura

- O sistema **não** contemplará otimizações de infraestrutura para suporte a alto volume de usuários simultâneos além do definido no RNF09
- O sistema **não** oferecerá SLA formal de disponibilidade além do definido no RNF07
