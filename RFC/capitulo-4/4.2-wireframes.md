# 4.2 Wireframes das Telas

Esta seção apresenta os wireframes das principais telas da aplicação. Os wireframes representam a estrutura e organização da interface em baixa fidelidade, com foco no fluxo de uso e na disposição dos elementos, sem detalhar aspectos visuais finais.

---

## 4.2.1 Home / Landing Page

A tela inicial apresenta a ferramenta ao usuário, com foco em comunicar o propósito da aplicação e direcionar para o acesso ou cadastro.

**Componentes principais:**
- Apresentação da ferramenta e proposta de valor
- Call-to-action para Login ou Cadastro
- Seção introdutória sobre o modelo C4

![Wireframe — Home / Landing Page](../assets/wireframe-01-home.png)
*Wireframe 1 — Home / Landing Page*

---

## 4.2.2 Login e Cadastro

Telas de acesso à plataforma. O cadastro redireciona para o login após a criação da conta. A recuperação de senha é acessada a partir da tela de login.

**Ações principais:**
- Preencher e-mail e senha
- Criar nova conta
- Recuperar senha por e-mail

*Wireframe 3 — Cadastro*

## 4.2.3 Dashboard

Tela principal após autenticação. Lista os projetos do usuário e permite criar novos. Exibe tela vazia com call-to-action quando não há projetos cadastrados.

**Ações principais:**
- Visualizar projetos existentes
- Criar novo projeto
- Acessar ou excluir um projeto

## 4.2.4 Criação de Projeto

Modal ou tela para criação de um novo projeto, com campos de nome e descrição. O nome é obrigatório conforme [RN04](../capitulo-2/2.5-regras-de-negocio.md).

**Ações principais:**
- Preencher nome do projeto (obrigatório)
- Preencher descrição (opcional)
- Confirmar criação ou cancelar

## 4.2.5 Editor de Diagramas

Tela central da aplicação, dividida em quatro regiões principais:

| Região | Descrição |
|--------|-----------|
| **Barra de identidade** | Logo à esquerda e nome do projeto à direita |
| **Barra de controles** | Desfazer/Refazer, toggle Visual/Textual e botão Exportar |
| **Sidebar esquerda** | Biblioteca de elementos C4 disponíveis para o nível selecionado, ocultada quando o nível não está selecionado |
| **Canvas central** | Área de trabalho onde o diagrama é construído via drag & drop ou entrada textual |
| **Barra inferior** | Seletor de nível C4 (Contexto \| Container \| Componente \| Código) e acesso ao Assistente Inteligente |

**Ações principais:**
- Arrastar elementos da sidebar para o canvas
- Conectar elementos
- Alternar entre níveis C4 pela barra inferior
- Desfazer e refazer ações
- Alternar entre modo visual e textual (texto → canvas)
- Exportar diagrama
- Acionar o Assistente Inteligente

![Wireframe — Editor de Diagramas](../assets/wireframe-07-editor.png)
*Wireframe 7 — Editor de Diagramas*

## 4.2.6 Modal de Edição de Elemento

Acionado ao interagir com um elemento no canvas, exibe um formulário para edição das propriedades do elemento selecionado, conforme [RF22](../capitulo-2/2.3-requisitos-funcionais.md).

**Campos do formulário:**
- Título
- Subtítulo / Descrição
- Relacionamentos — ligações com outros elementos

**Ações principais:**
- Editar propriedades do elemento
- Confirmar alterações
- Cancelar edição

![Wireframe — Modal de Edição](../assets/wireframe-08-modal-edicao.png)
*Wireframe 8 — Modal de Edição de Elemento*

---

## 4.2.7 Overlay de Sugestões IA

Painel ocultável acionado pelo usuário, que exibe a lista de sugestões e componentes recomendados pela assistência inteligente com base no contexto do projeto, conforme [RF16](../capitulo-2/2.3-requisitos-funcionais.md) e [RN12](../capitulo-2/2.5-regras-de-negocio.md).

**Características:**
- Exibição não obstrutiva — não bloqueia o canvas
- Sugestões são apenas orientativas; o usuário pode ignorá-las
- Ocultável a qualquer momento

![Wireframe — Overlay de Sugestões](../assets/wireframe-09-overlay-sugestoes.png)
*Wireframe 9 — Overlay de Sugestões IA*

---

## 4.2.8 Exportação

Painel ou modal de exportação, acessado pela barra superior do editor. Permite selecionar o formato desejado e confirmar o download.

**Formatos disponíveis:**
- PNG — imagem do diagrama
- PDF — documento do diagrama
- Docs-as-Code (`.json` / `.c4`) — arquivo estruturado para versionamento ([RF21](../capitulo-2/2.3-requisitos-funcionais.md))
