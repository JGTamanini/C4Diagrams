## Sobre o Projeto

Este repositório contém tudo sobre a documentação técnica e os artefatos de desenvolvimento do projeto ligado a uma **aplicação web voltada à diagramação de arquiteturas de software no padrão C4**.

O modelo C4 é uma das abordagens mais completas para representação arquitetural, organizando o sistema em diferentes níveis de abstração — do contexto geral até os componentes específicos. Apesar de seus benefícios, sua aplicação prática exige esforço e conhecimento que muitas vezes não são suportados pelas ferramentas disponíveis no mercado.

Este projeto nasce da observação de uma lacuna real: **as ferramentas existentes funcionam como editores gráficos passivos**, sem oferecer orientação conceitual, validação ou suporte durante o processo de modelagem. O resultado são diagramas inconsistentes, especialmente entre usuários com menor experiência.

A solução proposta vai além da simples criação de diagramas — ela busca **guiar o usuário** ao longo de todo o processo de modelagem, com:

- Interface visual baseada em Drag & Drop e entrada textual estruturada
- Validação automática da estrutura dos diagramas
- Assistência inteligente baseada em IA para orientação e revisão dos diagramas
- Suporte explícito aos 4 níveis: **Contexto → Container → Componente → Código**

---

## Público-Alvo

A ferramenta é projetada para **estudantes de computação** e **desenvolvedores em início de carreira** — pessoas que precisam trabalhar com modelagem arquitetural, mas ainda estão construindo sua base de conhecimento no modelo C4.
